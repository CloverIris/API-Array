# API ARRAY

API ARRAY 是一个面向 Windows 10/11 的本地优先 API 控制平面。它帮助个人开发者和小型组织安全管理多个 AI API，通过可视化节点编排完成能力探测、协议归一化、路由、故障切换、审计与本地高性能发布，并为发布后的能力生成可直接运行的活文档和多语言调用模板。

当前项目处于产品设计冻结阶段，尚未开始代码实现。
