# API ARRAY 产品设计文档 V0.2：API 钱包与项目画布变更

状态：冻结变更 · 2026-07-11  
基线：`API_ARRAY_产品设计文档_V0.1.md`

## 目标

桌面首页从泛化概览调整为工作台：左侧是 API 钱包，右侧是当前画布。普通用户先理解“我有哪些 API、哪个可用、能否直接拿来用”，再按需进入节点编排。

## 冻结交互

- API 钱包属于当前工作区，不跨工作区自动共享。内置 Provider 以无 Key 的目录卡显示，不暗示已添加、可用或有余额。
- 一个钱包资产引用一个 Provider Instance；同一 Provider 可建立多个实例。显示名冲突时建议添加连续数字，Secret 仍只保存在系统凭据存储。
- Gallery 支持名称模糊搜索及名称、健康、用量排序。卡片使用本地 SVG 标识、状态、预算环和明确的“估算”标记。
- 用量来自审计中的真实请求数据。费用仅按用户覆盖规则或内置 YAML 规则估算；规则要显示来源和版本，未知价格不得伪造金额。
- 点击资产仅生成内存中的浅蓝预放置 Provider Group；确认前不得写入工作区、图、Runtime 或 Secret。确认后将 Group 接入当前画布的总输出器；取消不留下任何配置。
- 一个项目包含文件夹和多个画布。每个新画布恰有一个总输出器和至多一个绑定本地 Publisher；项目间可复用同一钱包资产。
- 画布运行只启动其绑定 Publisher；暂停停止其接收请求；刷新只执行已引用 Provider 的无副作用体检；删除只删除画布专属 Publisher/Token、图和 UI 状态，不删除钱包资产或上游 Secret。

## 数据与安全边界

- Workspace Schema V2 独立于 Provider 与 Graph Schema。V1 工作区会迁移为默认项目、文件夹和画布；多输出旧图保留为 legacy 画布，禁止静默丢失数据。
- 节点图表达当前画布；坐标、缩放、分组折叠属于 UI 状态，永不作为 Runtime 语义。
- 基础 Provider Group 与 Publisher 路由的更新必须通过受控桌面命令，并在校验成功后保存。前端不接触 Secret 值、原始上游 Authorization Header 或任意文件系统接口。
- 预放置、刷新结果、错误和导出不得包含明文 Key、Publisher Token 或供应商账单凭据。

## 桌面布局

- 顶部仍为统一 44px 标题/工具栏；右侧 Inspector 默认覆盖，不压缩工作台。
- 左侧栏顶部展示 Project Tree，并为每个 Canvas 提供运行、暂停、刷新、删除操作；所有图标操作都有 Tooltip、标签和禁用/错误说明。
- 工作台默认约 360px API 钱包 + 自适应 React Flow 画布。专业节点页继续存在，但不创建第二套运行配置。
- 所有控件、状态和主题遵循 Apps SDK UI 的语义令牌和可访问性基线；亮色、暗色、系统主题与不透明降级均可读。
# V0.2 补充：Canvas 独立工作台与两级信息架构

> 本节是对钱包与多画布设计的强制收口；若与本文前部的“当前画布”描述冲突，以本节为准。

## 两级产品边界

- 全局层只管理运行总览、API 钱包、综合器总览、Publisher 总面板、审计与设置。
- Project 与 Folder 只承担组织职责，不是运行边界。
- Canvas 是唯一正式编辑和运行边界。每个 Canvas 独立持有图、草稿版本、已应用版本、至多一个 Publisher、活文档和运行记录。
- API 钱包属于 Workspace，可被多个 Canvas 引用；删除 Canvas 永远不得删除钱包资产或上游 Secret。

## 导航与交互

- 侧栏采用单列结构：顶部是全局入口，中部列出所有 Project / Folder / Canvas，底部是审计与设置入口。
- Canvas 行只显示名称和运行状态，点击进入专属工作台；重命名、移动、复制和删除进入悬浮菜单。
- 运行、暂停、停止与刷新位于 Canvas 工作台顶部，不在侧栏堆叠控制按钮。
- Canvas 工作台固定包含概览、编排、API 与路由、Publisher、活文档、运行记录六个页签。

## 数据与可靠性

- Workspace Schema V3 不再保存 active Project/Canvas；选择状态属于 WorkspaceUiState V3。
- 所有 Canvas 写命令必须显式携带 `projectId + canvasId`。禁止根据 UI 当前选中项隐式确定写入目标。
- 保存图只更新草稿；运行时校验并应用该 Canvas 的草稿。运行中继续编辑必须显示“运行快照 / 未应用草稿”。
- 复制 Canvas 复制图与路由配置，但不得复制 Publisher Token、监听端口或运行状态。
- 任何 IPC 缺失数组或映射时，前端必须降级为空集合；不得直接对未校验数据执行 `.map()`。
